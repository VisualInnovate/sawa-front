# Enable 360 — الديمو التفاعلي

يشغّل واجهة النظام الحقيقية (هذا المستودع نفسه) داخل إطارَي «حاسوب» و«هاتف»، مع خادم وهمي داخل المتصفح (`demo/mock`) بدل الـAPI، وطبقة إخراج فوقهما (المؤشر، البطاقات الطائرة، العدّادان، المدار، ملاحظات المقدّم). كل صفحة تظهر كما هي حرفياً.

## التشغيل
```bash
npx vite --config demo/vite.config.js
```
ثم `http://localhost:5180/demo/`. المفاتيح: ← التالي · → رجوع · 0–9 قفز · R إعادة · S تخطّي الحركة · P إيقاف · F ملء الشاشة · N ملاحظات المقدّم.

## التخصيص (زر «🎨 تخصيص» في شريط التحكم)
- **الشعار**: رفع PNG/SVG/JPG (يُصغَّر إلى 640px ويُحفظ data URL). يحلّ محل شعار النظام في كل صورة مصدرها `sawa_logo*.svg` أو `logo*.png` داخل الإطارَين (لوحة التحكم، التقارير، بوابة الأهل، أيقونة التبويب) وفي رأس الشِّل.
- **الألوان**: الأساسي (عائلة التركوازي `#135c65`: لوحة التحكم وPrimeVue) والثانوي (عائلة الأرجواني `#b21553`: بوابة الأهل) + تدرّجات جاهزة. التطبيق في `demo/brand/inFrame.js` داخل كل إطار: يمشي على قواعد CSS المحمَّلة (CSSOM) وعلى style/fill/stroke المضمّنة، ويبدّل كل لون قريب من تدرّج العائلة بما يقابله من اللون الجديد مع الحفاظ على إضاءته، ويحفظ الأصل للرجوع. رسوم Chart.js على canvas تبقى بألوانها.
- الحالة في `localStorage["demo:brand"]` (الأصل مشترك): الشِّل يكتبها والإطاران يلتقطانها فوراً عبر حدث `storage`؛ تبقى في المتصفح حتى «استعادة الافتراضي».
- **ملء الشاشة**: زر «⛶ ملء الشاشة» أو المفتاح F (Fullscreen API)؛ وF11 الأصلي للمتصفح يفي بالغرض أيضاً.

**للعرض الفعلي استخدم النسخة المبنية لا خادم التطوير** (خادم التطوير يحوّل كل صفحة عند أول فتح وقد ينتظر الإطار ثوانيَ):
```bash
npx vite build --config demo/vite.config.js
npx vite preview --config demo/vite.config.js --port 5181
```
ثم `http://localhost:5181/demo/` (في `.claude/launch.json`: `enable360-demo-dist`). الناتج `demo-dist/` (~21 MB) يُستضاف ثابتاً مع تحويل كل المسارات إلى `index.html`. أبقِ نافذة المتصفح ظاهرة أثناء العرض: المتصفح يبطّئ مؤقتات الصفحة المخفية.

## البنية
- `demo/scenario.ts` السيناريو (يوسف والأهل والموظفون والتواريخ النسبية).
- `demo/mock/` الخادم الوهمي: `backend.ts` (جدول المسارات، النداءات غير المعالَجة تُسجَّل في `__demoBackend.unknown`)، `db.ts`، `handlers/*`.
- `demo/src/engine/` المحرّك: `actions.ts` (أفعال الفصل)، `frames.ts` (إيجاد العناصر داخل الإطارات)، `player.ts`، `useDirector.ts`، `useBrand.ts` + `fullscreen.ts`.
- `demo/brand/` التخصيص: `brand.js` (الحالة وحساب الألوان، مشترك) و`inFrame.js` (التطبيق داخل الإطار، يُستدعى من `mock/install.js`).
- `demo/src/chapters/` الفصول؛ كل فصل: `start` (مسارا الإطارَين) + `apply(db)` (أثره في الحالة للقفز) + `timeline` (الحركة).
