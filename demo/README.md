# Enable 360 — الديمو التفاعلي

يشغّل واجهة النظام الحقيقية (هذا المستودع نفسه) داخل إطارَي «حاسوب» و«هاتف»، مع خادم وهمي داخل المتصفح (`demo/mock`) بدل الـAPI، وطبقة إخراج فوقهما (المؤشر، البطاقات الطائرة، العدّادان، المدار، ملاحظات المقدّم). كل صفحة تظهر كما هي حرفياً.

## التشغيل
```bash
npx vite --config demo/vite.config.js
```
ثم `http://localhost:5180/demo/`. المفاتيح: ← التالي · → رجوع · 0–9 قفز · R إعادة · S تخطّي الحركة · P إيقاف · N ملاحظات المقدّم.

البناء: `npx vite build --config demo/vite.config.js` → `demo-dist/` (استضافة ثابتة مع تحويل كل المسارات إلى index.html).

## البنية
- `demo/scenario.ts` السيناريو (يوسف والأهل والموظفون والتواريخ النسبية).
- `demo/mock/` الخادم الوهمي: `backend.ts` (جدول المسارات، النداءات غير المعالَجة تُسجَّل في `__demoBackend.unknown`)، `db.ts`، `handlers/*`.
- `demo/src/engine/` المحرّك: `actions.ts` (أفعال الفصل)، `frames.ts` (إيجاد العناصر داخل الإطارات)، `player.ts`، `useDirector.ts`.
- `demo/src/chapters/` الفصول؛ كل فصل: `start` (مسارا الإطارَين) + `apply(db)` (أثره في الحالة للقفز) + `timeline` (الحركة).
